# 自瞄参数（abu-aim / js-aim 共用思路）

| 参数 | 当前值 | 说明 | 调大会怎样 |
|---|---|---|---|
| 截图限速 | 45ms | 两次截屏最小间隔 | 帧率掉，截图进程堆积 |
| 降采样宽 | 360px | 找色前缩到多宽 | CPU 飙升 |
| 自瞄圈半径 | 传入参数 `radius` | 只在屏幕中心这块找目标 | 圈过大→误锁远处目标 |
| 目标色 | 红色能量重心 | 血条 / 人物高亮 | 换皮肤必须重标定 |
| 平滑系数 | — | 位移插值，越小越硬 | 太硬像瞬移，太软甩不动 |
| 头部偏移 | — | 锁点相对方框顶部的比例 | 偏了就是打脖子/打天 |

## 坐标系（两套，别串）

| 用途 | 坐标系 | 出处 |
|---|---|---|
| 自瞄锁点 | `3392x2400` 横屏 | `AimProvider.find()` 注释 |
| ESP 渲染 / `aff` 矩阵 | `2414x1080`（overlay 启动参数） | `start_esp.sh` |

## 标定步骤（换设备 / 换分辨率必做）

1. 截一张实际画面，标出人物血条颜色值（RGB）
2. 把颜色阈值写进 `PixelAimProvider`，跑单帧测试确认重心落在胸口以上
3. 用 `abu-aim/work/aim1.png`~`aim6.png` 这类实测图回归
4. 锁点偏移按方框高度比例算，别写死像素
